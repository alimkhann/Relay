How should different edge types look?

You have 3 explicit relation types + similarity edges. Each needs a distinct visual.

Your relation types

supersedes — item A replaces/invalidates item B
extends — item A builds upon item B
derives — item A was merged/derived from item B
similar — vector-similarity fallback (no explicit relation)

A

Color-Coded Edges

Each relation type gets a distinct color:

━━━ supersedes (red — destructive/replacing)
━━━ extends (blue — building on)
━━━ derives (purple — lineage)
╌╌╌ similar (gray dashed — weak/implicit)

Clear at a glance. Risk: colorful spaghetti if many edges.

B

Style-Coded (Subtle)

Same muted color, different line styles:

━━━━━━ supersedes (solid, thicker)
━ ━ ━ ━ extends (dashed)
╌╌╌╌╌╌ derives (dotted)
╌╌╌╌╌╌ similar (dotted, very faint)

Clean, minimal. Edges don't compete with nodes. Harder to distinguish from afar.

C

Hybrid — Subtle Default, Color on Interaction

Default state: All edges same muted gray, varying only in opacity (explicit=stronger, similar=fainter). Directed edges have small arrows.

On hover/click of a node: Connected edges reveal their type color + animate a pulse along the edge direction. Unrelated edges dim further.

Best of both: clean default view, rich info on interaction. Matches A+C interaction model.
