How should node interactions work?

Pick the interaction model that feels right for exploring project memory

A

Hover-Rich (Obsidian-style)

Hover: Node expands slightly, shows title + type badge + decay indicator. Connected edges highlight. Adjacent nodes glow.

Click: Opens inline detail panel (slides in from right) with full content, edit button, relations list. Node stays highlighted.

Double-click: Enters edit mode for that item directly in the panel.

Best for: exploration-first, seeing connections at a glance

B

Tooltip + Modal

Hover: Floating tooltip near cursor with title, type, decay score. Minimal — just enough to identify.

Click: Opens centered modal/dialog with full item details, edit form, relation links. Graph dims behind.

Double-click: Pins the node (prevents it from drifting in physics).

Best for: clean graph view, focused editing when needed

C

Progressive Disclosure

Hover: Node pulses, shows truncated title label that was hidden. Connected nodes + edges highlight with type-colored glow.

Click: "Focuses" the node — graph zooms to neighborhood, unrelated nodes fade to 20% opacity. Bottom sheet shows details.

Second click / Escape: Returns to full graph view.

Long press or right-click: Context menu with Edit, Pin, Archive options.

Best for: deep exploration, understanding relationships in context
