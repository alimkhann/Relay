# Support Policy

Relay currently uses a lightweight support model.

## Contact

- Product and billing support: support@onrelay.app
- Security issues: follow `SECURITY.md`

## What Gets Priority

- Production regressions
- Auth, billing, or data-loss issues
- MCP install breakage on officially supported clients
- Context-sync failures that affect active users

## Best-Effort Support

- Experimental client integrations
- Local environment quirks outside documented install paths
- Unrelated flaky tests that predate the change under review
